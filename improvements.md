# Auditoría de Portfolio — jorgemacias.dev

---

## 1. UX (Experiencia de Usuario)

### Lo que está bien

* Navegación clara y orden lógico (Hero → Sobre mí → Skills → Experiencia → Proyectos → Educación → Contacto)
* Diseño minimalista (sin ruido visual)
* Lectura rápida

### Problemas detectados

#### Hero no comunica stack

El mensaje es claro pero no indica tecnologías principales.

Ejemplo sugerido:

```
Full-stack developer
TypeScript • React • C# • Astro
```

---

#### Falta contexto en proyectos

Actualmente los proyectos dicen qué son, pero no:

* problema
* tecnologías
* rol

---

#### Falta demostración visual

Agregar:

* screenshots
* gifs
* demos

---

#### Formulario depende de JS

Si falla JS:

→ no hay contacto

---

## 2. Auditoría para Reclutadores

### Lo que está bien

* Experiencia profesional
* Proyectos personales
* Educación

---

### Problema principal

Las descripciones son tareas, no impacto.

Ejemplo:

Antes:

```
Desarrollo de una API REST para recepción de datos
```

Después:

```
Desarrollé una API REST para procesar datos en tiempo real
```

---

### Stack principal no definido

Todo está al mismo nivel.

Sugerido:

```
Primary:
- TypeScript
- React
- Astro
- C#

Secondary:
- Python
- Lua
- PHP
```
